How logging works

Tap a set number to log it — one tap means you hit the target reps. Came up short? Tap it again to count down one rep at a time. The ↻ button swaps any exercise for another that fits the day. Profile and equipment can be changed any time in Settings.

Calibrate with a PT test

Ten hard minutes to size the training to you: 2 minutes each of max push-ups, sit-ups, and air squats (rest between stations), then a timed mile. Your counts set the bodyweight rep targets, sit-ups set the core doses, the mile sets the conditioning.
